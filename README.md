# CSSpatialNet

CSSpatiaNet: Cell-type specific spatial autocorrelation and covariance estimation for spot-based spatial data. 

This is an R package for estimating the spatial autocorrelation and covariances for each cell type within spot-based spatial data. This includes all functions for obtaining estimates and uncertainty quantification through standard errors of each parameter.
